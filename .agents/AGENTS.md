# Agent Coding Guidelines & Workspace Rules

## Documentation Requirements
- **Mandatory Docstrings**: Every function, constant, module, struct, enum, and method created or updated in this codebase must have a clear Rust documentation comment (`///` for items or `//!` for module level).
- **Docstring Format**:
  - A brief summary line describing what the function does.
  - `# Parameters`: Explanation of each input parameter.
  - `# Returns` / `# Errors`: Explanation of return value and potential error scenarios.
- preserve code comments and documentation during code refactoring.
